# Security model

The trust root is a private per-installation CA. Pairing requires an out-of-band single-use 256-bit invite (120 seconds) and client CSR proof of possession. All business calls require TLS 1.3, certificate identity and an active device generation. Server identity/SAN is always verified. This is a native protocol: browser origins and browser fetch metadata are rejected. Do not expose raw Codex App Server or the DSH web UI as the RemoteDesk protocol.

State/private keys are current-user-only (POSIX 0700 / protected Windows owner ACL). Local administrators and processes already running as that user can access host engine credentials; this bridge does not sandbox the native model client itself or defend against a compromised host, Docker daemon, root/admin, or a malicious installed image. Remote model tools have only the three registered RemoteDesk tools. Codex native environment tools, MCP, plugins, hooks, browser and subagents are disabled for these sessions. DSH uses scoped native tools plus an exact-agent/executor guard, preserving unrelated local agents.

Commands run in a non-root Docker Linux container, current project bind mount, no network, read-only root, dropped capabilities, no-new-privileges and bounded resources. The whole project mount is writable for an approved command; .git, .agents, .codex and any secrets inside the project are included. File reads and diffs use a read-only mount. Path traversal/symlinks cannot reveal unmounted host paths. Approving a command grants that command any project mutation, including deletion or Git history changes; review it before accepting. The bridge does not promise arbitrary host commands, network tools or Docker escape protection against kernel vulnerabilities.

Images are base64 PNG/JPEG, text is valid UTF-8, at most 512000 bytes each and four per turn. Uploads are scoped to device/project for one hour; the engine may retain inputs in normal session history. History is accessible to every device authorized for that project, not only its author. Pair only trusted controllers and select projects whose contents may be sent to the configured model provider. Do not put bridge state, private keys or other hosts' state inside any exposed project.

Write leases are 90 seconds; approvals are tied to the initiating device, generation, session and lease, expire after five minutes, and accept one reply. Disconnect or lease expiry prevents new approval but does not silently cancel work. Explicit device revocation closes streams and cancels that device's owned remote work. An upstream turn-completed notification cannot release the lock: the native adapter also waits for every local tool callback and checks that its recorded containers are gone. Unconfirmed cleanup blocks new tool calls and later turns, retains the lock, and reports execution.blocked. Idle releases and revocation are serialized with session control to prevent an old completion from unlocking a newer turn. The shared project lock excludes other RemoteDesk controllers on the same canonical project only; native editors, local agents and other software do not participate.

Mutations persist a recognized 24-hour submission epoch and original operation ID before dispatch. Receipts last at least seven days beyond epoch expiry. Transport loss never proves failure: an unknown outcome must be reconciled, never silently resent with a new identity. A crashed service requires local inspection/recover; it does not auto-restart or steal locks. Start and recovery serialize through a crash-released local SQLite lock. Recovery removes recorded owned containers before releasing any project lock; an unavailable Docker daemon keeps those locks in place.

Report vulnerabilities through the repository's private security advisory channel when available. Do not attach invites, tokens, private keys, raw user transcripts or project data to public issues. Release checksums are integrity evidence from the same source, not an independent cryptographic signature.

RemoteDesk uses a dedicated controlled model catalog and empty native environments on every model turn. Native AGENTS loading, native environment tools, bundled skills, notifications and external orchestration hooks are disabled; project instructions can be read through the container tool. The RemoteDesk instruction/tool profile is intentionally narrower than a normal Codex desktop/CLI session.
