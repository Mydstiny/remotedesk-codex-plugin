# 本机控制面板

插件提供一个独立的本机管理面板，用于查看服务状态、管理项目和管理已配对设备。面板是插件命令的一部分，不会改变远程桥接协议或 HarmonyOS 应用的连接流程。

启动服务后，在另一个终端运行：

~~~sh
node bin/remotedesk-codex.mjs panel --state "$HOME/.remotedesk/codex"
~~~

Codex 面板使用上面的命令；如果同时部署 DSH，请在 DSH state 上运行 remotedesk-dsh.mjs panel。也可以用 --port 0 让系统分配空闲的本机端口。命令会输出一次带短期面板令牌的 URL；只在本机浏览器打开，不要把 URL 贴到聊天、日志或工单中。

面板包含：

- 服务监听地址、端口、锁文件和进程状态；
- 已配置项目的 ID、名称和本机路径；
- 已配对设备、角色、授权项目、撤销和过期状态；
- 生成 120 秒有效的 viewer/operator 配对邀请；
- 通过本机表单添加项目。

面板只绑定 127.0.0.1，所有 API 请求还需要启动时生成的随机令牌。项目添加会写入插件的私有 state；服务需要按常规流程重启后加载新的项目配置。撤销会立即更新设备授权状态。

协议当前没有客户端在线心跳。面板显示的是服务进程和配对授权状态；“已配对”不代表客户端此刻在线。真正的远程连接仍须由客户端通过 mTLS 握手和协议请求验证。
